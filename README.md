# EasytimeSplat for Unreal Engine 5.6

This repository contains the packaged `EasytimeSplat` plugin, version 1.1.0.

## Install

Copy `Plugins/EasytimeSplat` into the `Plugins` directory of an Unreal Engine 5.6 project, then enable the plugin in Unreal Editor. The included editor binaries are for Win64.

This is a packaged build. The `Source` directory contains module build rules and shader files, but not the plugin's C++ implementation. The packaged `Binaries` and `Intermediate` directories are retained as supplied.

License notices are in `Plugins/EasytimeSplat/LICENSE.md` and `Plugins/EasytimeSplat/LICENSE_ThirdParty_splat.md`.
